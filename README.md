# Widget Page Builder

헤더 · 히어로 · 콘텐츠 · 푸터를 **위젯 단위로 쌓아서** 한 페이지를 만들고, 완성된 페이지를 HTML 파일 하나로 내보내는 브라우저용 도구입니다. 설치나 서버 없이 `index.html`만 열면 동작합니다.

## 사용 방법

1. `index.html`을 브라우저로 엽니다. GitHub Pages: https://pearljng.github.io/widget-page-builder/
2. 왼쪽 사이드바 **페이지 구성**에서 `섹션 추가`로 위젯을 고릅니다(분류 탭 · 검색 지원). 선택한 섹션 아래의 아이콘으로 위·아래 이동, **바꾸기**(같은 자리에서 다른 위젯으로 교체), 복제, 삭제를 합니다. 사이드바는 접을 수 있습니다.
3. 오른쪽 패널에서 색 · 글꼴 · 크기 · 간격 · 애니메이션을 조절합니다.
4. 편집 화면에서 바로 고칠 수 있습니다.
   - 클릭: 요소 선택(해당 설정이 열림)
   - 더블클릭: 글자 바로 고치기 / 이미지·영상 바꾸기
   - 끌기 또는 방향키: 위치 이동 (`Shift`와 함께 10px)
   - `⌘Z` / `Ctrl+Z` 되돌리기, `⌘⇧Z` / `Ctrl+Y` 다시 실행
5. 편집 화면은 페이지 전체 높이로 보입니다. 상단의 기기 아이콘(PC 1920 · 태블릿 768 · 모바일 390)으로 너비를 바꾸고, 애니메이션 스위치로 움직임을 켜고 끕니다.
   - **미리보기**: 내보낼 HTML을 실제 기기 크기 화면에서 확인합니다. 고정 메뉴 · 스크롤 등장 애니메이션이 실제 사이트처럼 동작하고, 기기 전환과 `처음부터` 다시 보기를 지원합니다. `Esc`로 닫습니다.
6. **HTML 내보내기**
   - 페이지 HTML: `index.html`로 저장하면 그대로 완성된 페이지
   - 선택한 섹션만: 다른 페이지에 섹션 하나만 붙일 때
   - 페이지 데이터(JSON): 백업 · 다른 컴퓨터로 옮기기 · 복원

작업 내용은 브라우저의 localStorage에 자동 저장됩니다. 다른 브라우저나 컴퓨터로 옮길 때는 페이지 데이터(JSON)를 사용하세요.

|---|---|---|---|---|

| 히어로 | 타이포그래피 | H02 | Spotlight Statement | 풀스크린 사진 + 글자 단위 등장 + 마우스를 따라오는 빛 |
| 히어로 | 영상 슬라이드 | H03 | Cinematic Reel | 풀스크린 영상 슬라이드 + 진행 바 + 번호 이동 |
| 콘텐츠 | 텍스트 · 인용 | C01 | Pull Quote | 가운데 정렬 인용 문구, `**강조**` |
| 콘텐츠 | 텍스트 · 인용 | C09 | Image Message | 배경 이미지 + 흐림에서 또렷해지는 메시지 + 마지막에 올라오는 버튼 |
| 콘텐츠 | 숫자 · 지표 | C07 | Stat Counter | 큰 숫자 지표 + 카운트업 + 구분선 목록 |
| 콘텐츠 | 서비스 · 기능 소개 | C06 | Sticky Feature List | 왼쪽 고정 제목·메뉴(스크롤 연동) + 오른쪽 이미지 설명 목록 |
| 콘텐츠 | 카드 · 비교 | C03 | Choice Cards | 카드 2장 + 물리 엔진으로 떨어지는 태그 캡슐 + 원형 호버 |
| 콘텐츠 | 제품 · 갤러리 | C02 | Product Carousel | 가운데가 커지는 제품 캐러셀 + 설명 + 버튼 |

모든 위젯의 기본 내용은 **더미 데이터**(자리 표시 문구 · 크기가 적힌 회색 이미지)입니다. 실제 문구와 이미지로 바꿔서 사용하세요.

## 구조

```
index.html   빌더 전체 (위젯 정의 · 편집 화면 · 내보내기)
p/           미리보기용 글꼴 파일
```

위젯 하나는 아래 항목을 가진 객체입니다. 새 위젯은 같은 형태로 만들어 `WIDGETS` 배열에 추가하면 됩니다.

| 항목 | 역할 |
|---|---|
| `key`, `cat`, `group`, `no`, `title`, `sub`, `swatch` | 식별자, 분류(header·hero·content·footer), 그룹, 목록에 보일 이름과 설명, 썸네일 색 |
| `defaults()` | 기본 설정값 (더미 데이터 포함) |
| `groups` | 오른쪽 패널에 보일 설정 항목 |
| `css(settings)` · `html(settings)` | 설정을 받아 섹션의 CSS · HTML 생성 (위젯 ID로 스타일을 격리) |
| `run(root, cfg)` · `cfg(settings)` | 애니메이션 · 인터랙션 실행, 정리 함수를 반환 |
| `libs` | 필요한 외부 라이브러리 (예: GSAP, Matter.js) |
| `drag`, `multiline`, `rich`, `selectGroup` | 미리보기 끌기 · 더블클릭 편집 규칙 |

## 외부 리소스

- 일부 위젯은 [GSAP](https://gsap.com/)과 [Matter.js](https://brm.io/matter-js/)를 jsDelivr CDN에서 불러옵니다. 내보낸 페이지에도 자동으로 포함됩니다.
- 글꼴은 Google Fonts, jsDelivr(Pretendard, G마켓 산스)에서 불러옵니다.
