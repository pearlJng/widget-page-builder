# Widget Builder

히어로 · 콘텐츠 위젯을 **갤러리에서 하나씩 열어 다듬고**, 내 스타일로 저장하고, 완성한 위젯을 HTML 코드로 내보내는 브라우저용 도구입니다. 설치나 서버 없이 `index.html`만 열면 동작합니다.

## 사용 방법

1. `index.html`을 브라우저로 엽니다. GitHub Pages: https://pearljng.github.io/widget-page-builder/
2. **위젯 갤러리**에서 위젯을 고릅니다. 모든 위젯이 실제 모습 썸네일로 보이고, 분류 탭(전체 · 히어로 · 콘텐츠 · 내 스타일)과 검색을 지원합니다.
3. 카드의 `편집`을 누르면 그 위젯만 단독으로 열립니다.
   - 오른쪽 패널에서 색 · 글꼴 · 크기 · 간격 · 애니메이션을 조절합니다.
   - 클릭: 요소 선택(해당 설정이 열림)
   - 더블클릭: 글자 바로 고치기 / 이미지·영상 바꾸기
   - 끌기 또는 방향키: 위치 이동 (`Shift`와 함께 10px)
   - `⌘Z` / `Ctrl+Z` 되돌리기, `⌘⇧Z` / `Ctrl+Y` 다시 실행
   - 기기 아이콘(PC 1920 · 태블릿 768 · 모바일 390)으로 너비를 바꾸고, 애니메이션 스위치로 움직임을 켜고 끕니다.
   - **미리보기**: 실제 기기 크기 화면에서 확인합니다. 스크롤 · 등장 애니메이션이 실제 사이트처럼 동작하고, `Esc`로 닫습니다.
4. **내 스타일로 저장**: 고친 모습에 이름을 붙여 저장합니다. 저장한 스타일은 그 뒤 수정이 자동 저장되고, 갤러리의 `내 스타일` 탭에서 다시 열거나 이름 바꾸기 · 복제 · 삭제(카드의 `⋯` 또는 우클릭)를 할 수 있습니다. 기본형을 고친 뒤 저장하지 않고 나가면 확인 창이 뜹니다.
5. **HTML 내보내기**
   - HTML 파일: `index.html`로 저장하면 이 위젯 하나로 된 페이지
   - 붙여넣기용 코드: 이미 있는 페이지의 `<body>` 안에 붙여넣는 위젯 코드 (글꼴 · 스타일 · 스크립트 포함)
   - 설정 데이터(JSON): 보관 · 복원용. 같은 위젯을 열고 붙여넣은 뒤 `이 설정 적용`

내 스타일은 이 브라우저의 localStorage에 자동 저장됩니다. 다른 브라우저나 컴퓨터로 옮길 때는 설정 데이터(JSON)를 사용하세요.

모든 위젯의 기본 색은 **흑백**(검정 · 흰색 · 회색)이고 포인트 컬러가 없습니다. 강조색 · 버튼색 같은 설정은 남아 있어 필요하면 직접 바꿀 수 있어요. 이미지가 들어가는 모든 자리의 기본 이미지는 같은 자리 표시 이미지(밝은 회색 · 산 · 해 · 이름과 크기)입니다. 모든 위젯의 기본 내용은 **더미 데이터**(자리 표시 문구 · 크기가 적힌 회색 이미지)입니다. 실제 문구와 이미지로 바꿔서 사용하세요.

## 구조

```
index.html   빌더 전체 (위젯 정의 · 갤러리 · 편집 화면 · 내보내기)
p/           미리보기용 글꼴 파일
```

위젯 하나는 아래 항목을 가진 객체입니다. 새 위젯은 같은 형태로 만들어 `WIDGETS` 배열에 추가하면 됩니다.

| 항목 | 역할 |
|---|---|
| `key`, `cat`, `group`, `no`, `title`, `sub`, `swatch` | 식별자, 분류(header·hero·content·footer), 그룹, 목록에 보일 이름과 설명, 썸네일 색 |
| `defaults()` | 기본 설정값 (더미 데이터 포함) |
| `groups` | 오른쪽 패널에 보일 설정 항목 |
| `css(settings)` · `html(settings)` | 설정을 받아 섹션의 CSS · HTML 생성 (위젯 ID로 스타일을 격리) |
| `run(root, cfg)` · `cfg(settings)` | 애니메이션 · 인터랙션 실행, 정리 함수를 반환 |
| `libs` | 필요한 외부 라이브러리 (예: GSAP, Matter.js) |
| `drag`, `multiline`, `rich`, `selectGroup` | 편집 화면 끌기 · 더블클릭 편집 규칙 |

## 외부 리소스

- 일부 위젯은 [GSAP](https://gsap.com/)과 [Matter.js](https://brm.io/matter-js/)를 jsDelivr CDN에서 불러옵니다. 내보낸 페이지에도 자동으로 포함됩니다.
